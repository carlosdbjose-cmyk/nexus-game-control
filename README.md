# NEXUS GAME CONTROL

Painel interativo em HTML, CSS e JavaScript para demonstrar:

- SIMULAÇÃO VISUAL: apenas a interface do dashboard e indicadores visuais.
- CONTROLE REAL: explicação clara sobre o que pode ser feito com APIs nativas, permissões autorizadas e ajustes do sistema Android.

## Como abrir

Abra o arquivo `index.html` em um navegador.

## Observações

- Não há root, nem truques, nem manipulação do jogo.
- A simulação apenas altera a aparência da interface.
- O controle real depende de ajustes do sistema e do app nativo, não de HTML puro.

## Requisitos

- Navegador moderno.
- Compatível com desktop, tablet e mobile.
